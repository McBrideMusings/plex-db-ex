# ADR-0031: Readers reach the store only through the HTTP API

The store's SQLite files — `plexdb.db` and every snapshot published from it — are private to this repo's writer and explorer. Every other program reads the store through the explorer's HTTP API, where every fact the store holds for consumers has a route: each is a resource read with a GET and every list a page by cursor, and the one other method is the search that scores Shots on the server. The API's routes and their JSON shapes are the public interface; the tables behind them may change without a reader noticing, and no reader opens a store file, mounts a folder that holds one, or links a crate that reads one.

This supersedes [ADR-0001](./0001-one-writer-many-readers-sqlite-file-is-the-interface), [ADR-0003](./0003-rust-reader-crate-behind-a-plugin-capability-grant) and [ADR-0007](./0007-readers-get-a-snapshot-not-the-live-store) where they say a consumer opens the file or links `plexdb-reader`; the routes are listed in [The store API](../api).
